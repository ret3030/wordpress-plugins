# Velrion Admin

Jednoduchá administrace pro administrátory. Obecný plugin pro všechny weby.

## Co dělá

- **Jednoduché menu:** administrátor vidí jen vybrané hlavní položky menu (podmenu zůstávají celá). Výchozí výběr: Produkty, WooCommerce, Stránky, Média, Uživatelé, Pluginy, Nastavení, Snippety. Položky, které na webu nejsou, se ignorují.
- **Přepínač v horní liště:** „Celé menu“ / „Jednoduché menu“, každý administrátor zvlášť. Výchozí je jednoduché menu.
- **Výběr položek:** Nastavení → Jednoduché menu (nebo v horní liště „Upravit jednoduché menu“). Nastavení je v menu vždy.
- **Bez nástěnky:** v jednoduchém režimu Nástěnka v menu není a adresa `/wp-admin/` (i po přihlášení) vede rovnou na Produkty, na webu bez WooCommerce na Stránky. V režimu Celé menu je nástěnka jako dřív.
- **Aktualizace** (dřív pod Nástěnkou) jsou dostupné přes ikonu aktualizací v horní liště nebo v Celém menu.

Plugin jen schovává položky menu. Oprávnění administrátora se nemění, všechny stránky zůstávají dostupné přes celé menu nebo přímou adresu. Správce obchodu řeší plugin Velrion Shop Manager.
