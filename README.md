# Velrion Admin

Jednoduchá administrace pro administrátory. Obecný plugin pro všechny weby.

## Co dělá

- **Jednoduché menu:** administrátor vidí jen vybrané hlavní položky menu (podmenu zůstávají celá). Výchozí výběr: Nástěnka, Produkty, WooCommerce, Stránky, Média, Uživatelé, Pluginy, Nastavení, Snippety. Položky, které na webu nejsou, se ignorují.
- **Přepínač v horní liště:** „Celé menu“ / „Jednoduché menu“, každý administrátor zvlášť. Výchozí je jednoduché menu.
- **Výběr položek:** Nastavení → Jednoduché menu (nebo v horní liště „Upravit jednoduché menu“). Nastavení je v menu vždy.
- **Nástěnka** v jednoduchém režimu jen se Stavem webu, Aktivitou a přehledem WooCommerce, bez widgetů ostatních pluginů.

Plugin jen schovává položky menu. Oprávnění administrátora se nemění, všechny stránky zůstávají dostupné přes celé menu nebo přímou adresu. Správce obchodu řeší plugin Velrion Shop Manager.
